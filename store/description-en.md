# Drop Merge — Store Submission Materials

## Short description (CrazyGames / GameDistribution / itch.io)

Drop numbered tiles into the grid. Identical neighbors merge into a higher
number — chain merges for combo multipliers. Simple to learn, hard to put
down. How far can you push the numbers?

## Details

- Genre: Puzzle / Casual / Merge
- Controls: Mouse / Touch (tap a column to drop). Keyboard: ←/→ aim, ↓ or Space to drop.
- Features: Combo scoring, best-score saving, procedural graphics & sounds,
  single-file HTML5 (no external assets), works offline once loaded.
- Tech: Vanilla JavaScript, Canvas, WebAudio. No frameworks, no tracking.
