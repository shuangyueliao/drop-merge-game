# Drop Merge · 数字合合乐

A free, single-file HTML5 puzzle game. Drop numbered tiles, merge identical neighbors, chase combos. No dependencies, no build step, no tracking — one `index.html`.

**Play:** https://shuangyueliao.github.io/drop-merge-game/

- Mobile touch + desktop mouse/keyboard (←/→ aim, ↓/Space drop)
- Procedural graphics & WebAudio sounds (zero assets)
- Best score saved locally

## Submitting to portals

The game is a single self-contained HTML file, ready for HTML5 game portals
(CrazyGames, GameDistribution, itch.io). Fork/clone and submit.
